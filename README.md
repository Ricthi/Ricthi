# About Me

I’m **K. Richard Janas**, an **Graphic Designer, and Product Designer** building digital products across software, AI, web development, and visual design.

My work combines **Python development, modern web technologies, AI workflows, OCR, computer vision, UI/UX, 3D visualization, and interactive product experiences**.

I enjoy taking an idea from **problem definition to interface, implementation, testing, and a usable final product**.
